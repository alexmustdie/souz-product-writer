# Происхождение данных

Дата получения: 03.11.2026. Названия и производитель взяты из [выгрузки магазина](https://www.souz-pribor.ru/yml/any/feed.xml), поле `date` исходного YML: `2026-11-03T08:10:26+03:00`. В ней 47 978 offer-элементов, ни у одного нет `description`; параметры содержат только артикул и/или код товара. Два исходных offer-элемента сохранены в `offers.xml`.

| Пример | offer ID | Источник технических характеристик |
| --- | --- | --- |
| testo 510 | 58444 | https://souz-pribor.ru/product/testo-510/ |
| testo 608-H1 | 72404 | https://souz-pribor.ru/product/testo-608-h1/ |

Прямой запрос к адресу с `www` в этой среде возвращал 403. Тот же сайт без `www` отдавал страницы; технические данные взяты из них. Это подготовка примеров, сервис при генерации не скачивает сайт.

1. `testo-510.specs.txt` и `testo-608-h1.specs.txt` содержат исходный текст таблиц характеристик. В JSON названия параметров уточнены так, чтобы отличать температуру от влажности и не терять смысл погрешности. Многоточия и пробелы диапазонов нормализованы; значения и единицы не пересчитывались.
2. Поле `name` объединяет `typePrefix` и `name` из YML, `manufacturer` соответствует `vendor`.
3. Поле `description` представляет краткий пересказ назначения и функций из описания соответствующей карточки. Это подготовленный вход для генератора, а не автоматически извлеченный технический паспорт.
4. Для testo 510 подтверждены измерение перепада на фильтрах вентиляции/кондиционирования, подсветка, магниты, температурная компенсация и работа с опциональной трубкой Пито. Интерфейсы передачи данных в выбранном источнике не уточнены: значение null демонстрирует честное заполнение "данных нет".
5. Для testo 608-H1 использованы сведения о мониторинге влажности, температуры и точки росы, настольном размещении и перечисленных помещениях. Маркетинговые утверждения о водонепроницаемости, отсутствии необходимости в калибровке и долговечности не перенесены: в сохраненной таблице нет степени IP и достаточного технического подтверждения этих обещаний. Класс защиты оставлен неизвестным; это не утверждение об отсутствии защиты.
6. Параметры магазинов и модификаций могут расходиться с другими источниками. Эти входы демонстрируют работу по выбранным данным, а не независимую метрологическую экспертизу. Перед публикацией нужно сверить паспорт конкретной поставки.
